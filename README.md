## Desenvolvimento local

Copie `.env.example` para `.env` e preencha as variáveis do Supabase antes de iniciar o Vite:

```bash
npm install
npm run dev
```

Os comandos de validação disponíveis são `npm run typecheck` e `npm run build`.
